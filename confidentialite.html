Pourquoi

Pour traiter vos commandes, confier les missions, livrer les fichiers, vous payer ou vous facturer, contrôler la qualité et vous répondre. Nous n'utilisons pas vos données pour de la publicité et nous ne les vendons pas.

Qui voit quoi

Seule l'équipe Creative Studio voit les deux côtés. Un client ne voit jamais le profil d'un créatif ; un créatif ne voit jamais le nom ni les coordonnées d'un client. Les numéros, e-mails et liens écrits dans les messages sont masqués automatiquement. Ces règles sont appliquées dans la base de données elle-même.
